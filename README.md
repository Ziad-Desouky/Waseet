# 🚀 Waseet – Multi-Category Services Platform 

Waseet is a **team-based multi-category services platform** that connects service providers with customers through a modern and responsive web application.

The project was developed as part of a **university graduation project**, aiming to deliver a scalable system that combines frontend, backend, mobile, and AI-powered components.

> 📁 The **frontend web application** is located inside the `frontend` directory.

---

## 🧩 About the Project (Frontend Perspective)

From a frontend perspective, Waseet focuses on delivering a clean and intuitive user interface that supports multiple user roles (customers, service providers, and admins), while ensuring responsiveness, usability, and smooth interaction across different devices.

The web application acts as the primary interaction layer, integrating with backend APIs and AI-powered services to present data, manage workflows, and enhance the overall user experience.

---

## 🎯 Frontend Responsibilities

- Built responsive layouts for desktop and mobile devices  
- Implemented user-friendly UI components for dashboards and forms  
- Integrated frontend views with backend APIs  
- Ensured consistent design and smooth navigation across the application  
- Collaborated closely with backend, mobile, and AI team members  

---

## 🛠️ Frontend Technologies

- HTML  
- Tailwind CSS  
- JavaScript  
- React  
- Framer Motion (animations & UI transitions)

## 🚀 Installation & Run Locally

Follow these steps to run the **frontend application** locally:
### 1️⃣ Clone the repository
```bash
git clone https://github.com/Ziad-Desouky/Waseet.git
```
### 2️⃣ Move to the frontend directory
```bash
cd Waseet/frontend
```
### 3️⃣ Install dependencies
```bash
npm install
```
### 4️⃣ Run
```bash
npm run dev
```
